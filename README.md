
# Engineering College Website

## Project Description
A responsive multi-page website for an Engineering College.

## Technologies
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Pages
- Home
- Programs
- Admissions
- Student Life
- Contact
- Registration

## Features
- Responsive navigation menu
- Program information cards
- Contact form with demo feedback
- Student registration form with demo feedback
- Automatic copyright year

## How to Run
Open index.html in a web browser.

## Note
The forms are demonstration forms and do not send data to a server.
